# Fishing Log — спецификация MVP

Учёт рыболовных снастей: что у меня есть и где оно лежит.
Отдельное PWA, каркас копируется из fpv-log (fpv-log и shooting-log не трогаем).

## Основа

- Репо `fishing-log`, GitHub Pages, ванильный JS без сборки, IndexedDB, service worker.
- Из fpv-log: синхронизация через Google Диск, темы, uk (по умолчанию) + ru, «Что нового», напоминание о бэкапе, фото, QR-наклейки.
- Деньги в UAH. Длина в м, тест в г, шнур в PE и мм.

## Вкладки

**Снасти** · **Места** · **Ещё** (Хочу, настройки, бэкап). Открывается на «Снастях».

## Места хранения

- Дерево произвольной глубины: «Гараж → Шкаф → Ящик Plano №2».
- У вещи одно текущее место; в карточке и поиске виден полный путь.
- Переезд места переносит всё содержимое (вещи ссылаются на место, место — на родителя).
- QR-наклейка на место: скан → экран места со всем, что внутри (включая вложенные).
- Режим «добавляю в это место»: новые вещи получают место автоматически.

## Снасти

- Категории (редактируемые): удилища, катушки, шнуры и лески, приманки (воблеры, блёсны, силикон, мухи…), оснастка (крючки, грузила, вертлюжки, поводки), коробки и ящики, одежда, прочее.
- Поштучно: удилища, катушки, эхолот, подсак, ящики — своя карточка у каждой.
- Количеством: приманки, оснастка — позиция «Воблер X 110 SP, цвет 03 — 2 шт». Одна модель в двух местах = две записи.
- Общие поля: название, бренд, модель, цвет, цена, дата покупки, заметка, фото (одно, сжатое ~800 px). Всё кроме названия необязательно.
- Удилище: длина, тест, строй, число колен, тип (спиннинг / фидер / поплавок / нахлыст).
- Катушка: размер, передаточное число, запасные шпули.
- Связки: катушка ставится на удилище, шнур на катушку (с датой намотки).
- Статусы: в наличии / потеряна / сломана / продана / подарена. Не «в наличии» — скрыты из списка, остаются в истории. «−1 потерял» у количественных.
- Поиск по названию, бренду, модели, цвету, заметке + фильтр по категории.
- «Копировать» карточку (та же приманка другого цвета).
- Массовый перенос: выделить несколько вещей → другое место.

## Хочу

## Данные

- `starter.json`: категории + пример мест (Дом / Гараж / Машина).
- `demo.json`: ~10 вымышленных вещей для просмотра.
